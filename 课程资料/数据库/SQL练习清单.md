## D 多表连接（重点！你跳过的部分）

- D1 二表等值连接：001号课成绩降序显示学生姓名
  思路：`From Student, SC Where 连接条件 and SC."C#"='001' Order By Score Desc`
- D2 三表连接：'数据库'课成绩降序显示学生姓名
  思路：加 Course，连 `Student."S#"=SC."S#"` 和 `SC."C#"=Course."C#"`，再 `Course.Cname='数据库'`
- D3 同表连接 θ：有薪水差额的任意两位教师
  思路：Teacher 起别名 T1,T2，`Where T1.Salary > T2.Salary`
- D4 ⭐同表连接：既学001又学002的学号
  **先想**：为什么 `Where C#='001' and C#='002'` 不对？（一行 C# 只能一个值，恒空）
  正解思路：SC 起两个别名 S1,S2，`S1."S#"=S2."S#"`（同一人）and `S1."C#"='001'` and `S2."C#"='002'`
- D5 同表连接：001号课成绩比002号课高的学号（在 D4 基础上加 `S1.Score>S2.Score`）

## E 增删改（DML）

- E1 批量插入：把及格（Score>=60）的同学（S#,C#,Score）插到新表 SCt（先 `create table SCt(...)`）
  思路：`insert into SCt(...) select ... from SC where ...`
- E2 删除 98030101 的所有选课
- E3 删除有四门不及格的同学
  思路：`delete from Student where "S#" in (子查询)`；子查询在 SC 里 `where Score<60 group by "S#" having count(*)>=4`
  （当前数据没有四门不及格的，结果 0 行，但语法要会）
- E4 全体教师涨 5%
- E5 计算机系教师涨 10%
  思路：`where "D#" in (select "D#" from Dept where Dname='计算机')`

## F 修正撤销（DDL）

- F1 Student 加列 Saddr（`alter table ... add ...`）
- F2 Sname 类型改 char(10)（`alter table ... modify ...`）
- F3 ⭐delete vs drop 对比（亲手做，最直观）：
  - `delete from SC;` → `\d` 看 SC 还在不在（**在！结构保留**）
  - `drop table SC;` → `\d` 看 SC 还在不在（**没了**）
  - 理解：delete 删元组留壳，drop 连壳带元组全拆
