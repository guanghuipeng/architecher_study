## 怎么用

- **全文检索**：`grep -r "关键词" 教材知识库/`，或编辑器全局搜索。
- **回溯原书**：每页末尾有 `<!-- pN -->` 页标记，对应原书页码。要看加粗/图/排版，按页号翻对应 PDF。
- **标题层级**：来自原书书签（教程 527 条 / 32小时 38 条），章节结构完整。
