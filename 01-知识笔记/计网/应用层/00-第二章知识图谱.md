## 三、应用层协议对比矩阵

```
┌──────────┬──────────┬────────────┬──────────┬──────────┬──────────────┐
│  协议    │   用途   │  传输层     │  端口    │  架构     │  你学到什么   │
├──────────┼──────────┼────────────┼──────────┼──────────┼──────────────┤
│  HTTP    │  Web     │   TCP      │   80     │  C/S     │ 请求/响应模式 │
│  HTTPS   │  安全Web │TCP+TLS     │   443    │  C/S     │ 加密通信     │
│  HTTP/2  │  Web     │   TCP      │   80     │  C/S     │ 帧/多路复用  │
│  HTTP/3  │  Web     │   QUIC/UDP │   443    │  C/S     │ 0-RTT握手   │
│  SMTP    │  发邮件  │   TCP      │   25     │  C/S     │ Push模式    │
│  IMAP    │  收邮件  │   TCP      │   143    │  C/S     │ 服务器存邮件 │
│  POP3    │  收邮件  │   TCP      │   110    │  C/S     │ 下载到本地   │
│  DNS     │  域名解析 │   UDP/TCP │   53     │  层级    │ 分布式数据库 │
│  DASH    │  视频流  │   TCP      │   80/443 │ CDN+C/S │ 自适应码率   │
└──────────┴──────────┴────────────┴──────────┴──────────┴──────────────┘
```

## 四、学习路线图

```
第1天 ──→ §2.1 应用层原理 + §2.7 Socket 编程
          │  重点：建立"门"的心智模型
          │  实验：用 Python 写一个 TCP 聊天程序
          │
第2天 ──→ §2.2 HTTP（上）：请求/响应、状态码、Cookie
          │  重点：看懂 HTTP 报文长什么样
          │  实验：用 nc/telnet 手写 HTTP 请求
          │
第3天 ──→ §2.2 HTTP（下）：持久连接、缓存、HTTP/2、HTTP/3
          │  重点：理解非持久vs持久、HOL阻塞问题
          │  实验：Wireshark 抓 HTTP 包
          │
第4天 ──→ §2.3 电子邮件 + §2.4 DNS
          │  重点：SMTP push模式 vs HTTP pull模式
          │        DNS 是互联网最牛的分布式数据库
          │  实验：nslookup + dig 手动解析域名
          │
第5天 ──→ §2.6 视频流与CDN
          │  重点：DASH自适应码率、CDN分发架构
          │  实验：打开 B 站 F12 看视频分片请求
          │
第6天 ──→ 综合复习 + 刷卡片 + Wireshark 大实验
          │  用 Wireshark 追踪一次完整的网页加载
          │  看到 DNS→TCP握手→HTTP请求→响应 全流程
          │
第7天 ──→ Knowledge Check 自测 + 回顾卡片
```

## 五、这张图要刻在脑子里

```
你输入 URL 到看到网页，应用层发生了什么？

  www.bilibili.com
        │
        ▼
  ┌─────────┐
  │ ① DNS   │  解析域名 → 得到 IP 地址
  │   UDP:53│  www.bilibili.com → 120.240.xxx.xxx
  └────┬────┘
       │ IP 地址
       ▼
  ┌─────────┐
  │ ② TCP   │  三次握手建立连接（第3章详讲）
  │   端口80 │  你的机器 ←→ B站服务器
  └────┬────┘
       │ 连接建立
       ▼
  ┌─────────┐
  │ ③ HTTP  │  发送 GET / HTTP/1.1 请求
  │  请求   │  携带 Header: Host, User-Agent, Cookie...
  └────┬────┘
       │
       ▼
  ┌─────────┐
  │ ④ HTTP  │  服务器返回 200 OK + HTML
  │  响应   │  Content-Type: text/html
  └────┬────┘
       │ 解析 HTML，发现引用了 50 个资源
       ▼
  ┌─────────┐
  │ ⑤ 重复  │  对每个 JS/CSS/图片/视频 发起新的 HTTP 请求
  │  ①-④   │  (HTTP/2 可以复用连接，不用重新握手)
  └────┬────┘
       │
       ▼
  ┌─────────┐
  │ ⑥ 渲染  │  浏览器组装所有资源 → 你看到页面
  └─────────┘
```
