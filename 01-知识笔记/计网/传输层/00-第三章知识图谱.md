## 四、学习路线

```
第一步：§3.1-3.2 传输层概述 + 多路复用
  └── 理解传输层"为进程间通信服务"的定位
  └── 理解 TCP 用 4-tuple 区分连接，UDP 只用 port

第二步：§3.3 UDP
  └── 最简单的传输协议 → 作为 warm-up
  └── 理解为什么"不可靠"反而有用途

第三步：§3.4 可靠数据传输原理 ← 最重要！
  └── 从零开始设计一个可靠传输协议
  └── 每一步解决什么问题？为什么需要序号、ACK、定时器？
  └── GBN vs SR 的取舍 → TCP 选择了什么？

第四步：§3.5 TCP 协议详解 ← 你最关心的！
  └── TCP 段结构 (seq #, ACK #, rwnd, flags)
  └── 三次握手 (为什么不是两次?)
  └── 四次挥手 + TIME_WAIT
  └── RTT 估计 (指数加权移动平均)
  └── 流量控制 (接收窗口)

第五步：§3.6-3.7 拥塞控制
  └── 拥塞 vs 流量控制
  └── AIMD (加性增、乘性减)
  └── TCP 状态机：慢启动 → 拥塞避免 → 快速恢复
  └── TCP CUBIC、BBR

第六步：§3.8 传输层演进
  └── QUIC = 把 TCP 搬上 UDP
  └── HTTP/3 为什么快
```

## 五、第三章与其他章节的关系

```
Ch2 (应用层)
  │
  │  你的程序调用 socket API
  │  send() / recv() / sendto() / recvfrom()
  │
  ▼
Ch3 (传输层) ← 你现在在这里
  │
  │  TCP/UDP 把应用数据打包成 segment
  │  加上 port number → 交给网络层
  │
  ▼
Ch4 (网络层 - 数据平面)
  │
  │  IP 把 segment 打包成 datagram
  │  根据路由表转发
  │
  ▼
Ch5 (链路层)
  │
  │  把 datagram 打包成 frame
  │  在相邻节点间传输
  │
  ▼
物理层
```
