## B. 数字类（标准化 / 知识产权，最纯记忆）

- 专利保护期：发明 **20 年** / 实用新型 **10 年** / 外观设计 **15 年**
- 著作权：自然人**终身 + 死后 50 年**；法人/组织**首次发表后 50 年**
- **标准层级 7 档**（09-15 核大纲原文口径，从高到低）：**国际标准 → 美国标准 → 国家标准 → 国家军用标准 → 行业标准 → 地方标准 → 企业标准**
  - ⚠️ **"美国标准""国家军用标准"是软考特色考点**，常识里没有，最容易漏这两个
- **我国标准编号**（国标常识）：
  - **GB** = 强制性国家标准 ｜ **GB/T** = 推荐性国家标准（T=推荐）｜ **GB/Z** = 国家标准化指导性技术文件（Z=指导）
  - 行业标准举例：**SJ**（电子）· **YD**（通信）· **GA**（公共安全）
  - 地方标准 = **DB** + 行政区划代码 ｜ 企业标准 = **Q/** + 企业代号
- ⚠️ 大纲还要求：标准化意识、标准化的发展、**标准的生命周期**、代码标准 / 文件格式标准 / 安全标准 / 软件开发规范和文档标准、标准化机构 —— **教材未详写，待补**（考前专项）

## E. 知识产权（约 3 分，纯记忆；来源：《32小时通关》第 23 小时）

**E1. 知识产权 4 大特性**：无体性（抽象财富）· 专有性（只有权利人能用）· 地域性（只在授权国受保护）· 时间性（过期=全人类共同财富）

**E2. 计算机软件 = 计算机程序 + 有关文档**（《计算机软件保护条例》第二条）
- ⭐ **源程序和目标程序 = 同一作品**（不是两个）
- 受保护条件：开发者**独立开发** + **已固定在某种有形物体上**（**不要求登记**）

**E3. 归属（最爱考）**
| 情形 | 归谁 |
|---|---|
| 职务作品（一般） | 归**作者**；单位有"业务范围内优先使用"，且 **2 年内**作者不得许可第三人同方式使用 |
| 职务作品（**主要利用单位物质技术条件** + **单位担责**，含**计算机软件**） | 作者只留**署名权**，其余归**单位** |
| 委托作品 | **先看合同**；未约定 → 归**受托人**（创作方） |

**E4. 保护期**：署名权 / 修改权 / 保护作品完整权 → **不受限制**；其余 → 自然人**终身+死后 50 年**，法人**首次发表后 50 年**
（发明 **20** 年 / 实用新型 **10** 年 / 外观设计 **15** 年）

**E5. 不适用著作权法**：法律法规及官方译文 · 单纯事实消息 · 历法、通用数表/表格/公式

## F. 知识产权：专利 / 商标 / 商业秘密（来源：《32小时通关》第 23 小时 23.4–23.7）

**F1. 专利权的归属**
- **职务发明创造**（执行本单位任务 / **主要利用本单位物质技术条件**完成）→ 申请专利的权利属于**单位**，批准后**单位**为专利权人
- **非职务发明创造** → 属于**发明人 / 设计人**本人
- 合作完成 / 受委托完成 → 除另有协议外，属于**完成或共同完成的单位或个人**
- ⭐ **先申请原则**：两个以上申请人分别就同样的发明创造申请专利 → 专利权授予**最先申请的人**

**F2. 不授予专利权的 6 项**（多为选择题干扰项）
> 科学发现 · **智力活动的规则和方法** · 疾病的诊断和治疗方法 · 动物和植物品种 · 原子核变换方法及获得的物质 · 主要起标识作用的平面印刷品设计
（例外：动物和植物**品种的生产方法**可以授予专利权）

**F3. 商标**
- 同一种/类似商品上以相同或近似商标申请 → 公告**申请在先**的；**同一天**申请 → 公告**使用在先**的 ⚠️别把这两个顺序记反
- **不得作为商标使用**：国家名称/国旗/国徽/国歌/军旗等 · 与"红十字""红新月"相同近似 · 带有民族歧视性 · 带有欺骗性 · 有害社会主义道德风尚
- **不得作为商标注册**：仅有本商品的**通用名称/图形/型号** · 仅直接表示**质量/主要原料/功能/用途/重量/数量**及其他特点 · 其他缺乏**显著特征**的（**经使用取得显著特征并可识别的，可以注册**）
- 县级以上行政区划地名 / 公众知晓的外国地名不得作为商标（地名有其他含义、或作集体商标/证明商标组成部分的除外）

**F4. 商业秘密 3 要件**（《反不正当竞争法》）= **不为公众所知悉** + **具有商业价值** + **权利人采取相应保密措施** —— 对象是技术信息、经营信息等商业信息

## G. 专业英语：架构英语高频词（来源：《32小时通关》第 25 小时 —— 该小时就是历年英文题题库）

**G1. 高频术语（中英对照）**

| 英文 | 中文 |
|---|---|
| architectural style | 架构风格 |
| a vocabulary of components and connector types | 构件与连接器类型的**词汇表** |

| application architecture | 应用架构 |

| network architecture DFD | 网络架构数据流图 |

**G2. ⭐ 软件架构结构三大类**（出自 25.5 原题，英文阅读必考）

| 英文 | 中文 | 教材原口径 |
|---|---|---|
| **Module structures** | 模块结构 | 把决策体现为一组需要被**构建或采购的代码或数据单元** |
| **Component and connector structures** | 构件-连接器结构 | 把决策体现为系统如何被结构化为一组具有**运行时行为和交互**的元素 |
| **Allocation structures** | 分配结构 | 把决策体现为系统如何在其环境中关联到**非软件结构**（CPU、文件系统、网络、开发团队） |

**G3. ⭐ 四种主要非功能需求类型**（教材原文枚举，英文题爱挖空）
> **operational**（操作要求：操作环境及如何随时间变化）· **performance**（性能要求：响应时间 / 容量 / 可靠性）· **security**（安全要求：保护系统免受破坏和数据丢失）· **cultural and political**（文化和政治要求：特定国家）

**G4. 架构设计第一步**（25.2 原文）
> 第一步是把**非功能需求（nonfunctional requirements）细化为更详细的要求**，再用它帮助**选择架构**和**每个设备上放哪些软件构件**；然后才用需求和架构设计去开发**硬件与软件规范（hardware and software specification）**。

**G5. ⭐ 视图与评估的英文名**（来源：教程 5.1.4 图下英文名 + 8.2.1 原词；2026-09-23 补，专治"中文答对、英文选择题翻车"）

*4+1 视图的教材英文名（考英文题按这个认）*

| 英文 | 中文 | 谁看 |
|---|---|---|
| **Logical View** | 逻辑视图 | 最终用户（功能） |
| **Implementation View** | 实现视图 | 程序员（配置、装配） |
| **Process View** | 进程视图 | 系统集成人员（性能、可伸缩性、吞吐率） |

*架构评估（ATAM）核心词*

| 英文 | 中文 | 一句话 |
|---|---|---|
| **Sensitivity Point** | 敏感点 | 一个/多个构件的特性，只牵动**一个**质量属性 |
| **Tradeoff Point** | 权衡点 | **影响多个质量属性**的特性，＝**多个质量属性的敏感点** |
| **Utility Tree** | 效用树 | 树根→质量属性→属性分类→**质量属性场景（叶子）** |
| **Stakeholders** | 风险承担者 / 利益相关人 | 对架构施加影响以保证自己目标的人 |
| **Architecture Tradeoff Analysis Method** | ATAM | 架构权衡分析方法 |

## H. 未来信息综合技术（来源：《32小时通关》第 13 小时；该小时单选约 **3~5 分**，还覆盖案例与论文）

**H1. CPS 四大核心技术要素（口诀：一硬一软一网一平台）**
| 口诀 | 内容 | 地位 |
|---|---|---|
| **一硬** | 感知和自动控制 | CPS 实现的**硬件支撑** |
| **一软** | 工业软件 | CPS 的**核心** |
| **一网** | 工业网络 | **网络载体** |
| **一平台** | 工业云和智能服务平台 | **支撑上层解决方案的基础** |

**H2. 云计算服务方式 = 3 种**（⚠️ 干扰项常编"计算即服务"）
| 方式 | 提供什么（教材原话） |
|---|---|
| **SaaS** 软件即服务 | 把**应用软件**统一部署在云计算服务器上 |
| **PaaS** 平台即服务 | 把**分布式开发环境与平台**作为一种服务提供 |
| **IaaS** 基础设施即服务 | 把**多台服务器组成"云端"基础设施**作为计量服务提供给客户 |

**部署模式 = 4 种**：**公有云 · 社区云 · 私有云 · 混合云**

**H3. 大数据分析步骤（5 步）**
数据获取/记录 → 信息抽取/清洗/注记 → 数据集成/聚集/表现 → 数据分析/建模 → 数据解释
（应用领域：制造业、服务业、交通行业、医疗行业）

**H4. 机器学习按学习模式分类**

|---|---|
| 监督学习 | **已标注**的样本集 |
| 无监督学习 | **不需**标注 |
| 半监督学习 | **少量**标注 |
