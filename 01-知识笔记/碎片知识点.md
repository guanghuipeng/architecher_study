## A. 英文缩写全称（选择题高频，一个词 10 秒）

- ATAM = Architecture Tradeoff Analysis Method，架构权衡分析方法
- SAAM = Software Architecture Analysis Method，软件架构分析方法
- CBAM = Cost Benefit Analysis Method，基于成本的分析方法
- DSSA = Domain-Specific Software Architecture，特定领域软件架构
- ABSD = Architecture-Based Software Design，基于架构的软件设计
- SOA = Service-Oriented Architecture，面向服务架构
- ESB = Enterprise Service Bus，企业服务总线
- UDDI / WSDL / SOAP / REST（SOA 四大协议规范）
- CMMI = Capability Maturity Model Integration，能力成熟度模型集成
- NVP = N-Version Programming，多版本程序设计

## B. 数字类（标准化 / 知识产权，最纯记忆）

- 专利保护期：发明 **20 年** / 实用新型 **10 年** / 外观设计 **15 年**
- 著作权：自然人**终身 + 死后 50 年**；法人/组织**首次发表后 50 年**
- 标准层级（效力从高到低）：国际 → 国家（GB 强制 / GB/T 推荐）→ 行业 → 地方 → 企业

## C. 信息系统分类（常识，各给谁用）

- TPS 业务处理系统（基层操作）/ MIS 管理信息系统（中层管理）/ DSS 决策支持系统（高层决策）
- ES 专家系统（模拟专家推理）/ OAS 办公自动化 / ERP 企业资源规划

## E. 知识产权（约 3 分，纯记忆；来源：《32小时通关》第 23 小时）

**E1. 知识产权 4 大特性**：无体性（抽象财富）· 专有性（只有权利人能用）· 地域性（只在授权国受保护）· 时间性（过期=全人类共同财富）

**E2. 计算机软件 = 计算机程序 + 有关文档**（《计算机软件保护条例》第二条）
- ⭐ **源程序和目标程序 = 同一作品**（不是两个）
- 受保护条件：开发者**独立开发** + **已固定在某种有形物体上**（**不要求登记**）

**E3. 归属（最爱考）**
| 情形 | 归谁 |
|---|---|
| 职务作品（一般） | 归**作者**；单位有"业务范围内优先使用"，且 **2 年内**作者不得许可第三人同方式使用 |
| 职务作品（**主要利用单位物质技术条件** + **单位担责**，含**计算机软件**） | 作者只留**署名权**，其余归**单位** |
| 委托作品 | **先看合同**；未约定 → 归**受托人**（创作方） |

**E4. 保护期**：署名权 / 修改权 / 保护作品完整权 → **不受限制**；其余 → 自然人**终身+死后 50 年**，法人**首次发表后 50 年**
（发明 **20** 年 / 实用新型 **10** 年 / 外观设计 **15** 年）

**E5. 不适用著作权法**：法律法规及官方译文 · 单纯事实消息 · 历法、通用数表/表格/公式
